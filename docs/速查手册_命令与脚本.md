# 第 0 章 · 命令是怎么组成的

## 命令 = 程序名 + 选项 + 参数

```
sudo  docker  run  -d  --name  nc  -p  8091:80  myweb:nocopy
```

| 位置 | 词 | 是什么 |
|---|---|---|
| 1 | `sudo` | **另一个程序**，作用是"以 root 身份运行后面那条" |
| 2 | `docker` | 程序名 |
| 3 | `run` | docker 的**子命令**（动作） |
| 4 | `-d` | 选项（flag），docker 规定 = 后台运行 |
| 5–6 | `--name nc` | 选项 + 它的**值**（容器叫 nc） |
| 7–8 | `-p 8091:80` | 选项 + 的值（端口映射） |
| 9 | `myweb:nocopy` | 参数（用哪个镜像） |

---

## 四条规则

**规则 1：第一个词永远是程序。**

`docker`、`curl`、`mkdir` 都是程序（文件系统里真实存在的可执行文件）。

**验证：**

```bash
which docker
which mkdir
which curl
```


**规则 2：有些程序有「子命令」。**

| 程序 | 子命令 | 意思 |
|---|---|---|
| `docker` | `run` / `ps` / `build` / `exec` | 不同动作 |
| `git` | `add` / `commit` / `push` | 不同动作 |
| `apt` | `update` / `install` / `remove` | 不同动作 |
| `docker-compose` | `up` / `down` / `ps` | 不同动作 |
| `systemctl` | `start` / `stop` / `status` | 不同动作 |

**没有子命令的程序：** `ls`、`cat`、`mkdir`、`curl`、`ping`。

**规则 3：`-` 开头是选项，`--` 开头是长选项。**

| 形式 | 例子 | 说明 |
|---|---|---|
| `-d` | `docker run -d` | 单字母简写 |
| `--detach` | `docker run --detach` | 全名，意思一样 |
| `-p 8091:80` | 选项后面跟值 | 值可能用空格隔开 |
| `-p8091:80` | 也可以贴在一起 | 等价 |

**规则 4：选项和参数的顺序，多数程序不敏感。**

```bash
docker run -d nginx -p 8080:80
docker run -d -p 8080:80 nginx
```

**两条都能跑。** 但参数（`nginx`）必须是一个整体，不能拆。

---

## 选项是每个程序自己定义的

**`-p` 在三个程序里是三个意思：**

| 命令 | `-p` 的意思 |
|---|---|
| `docker run -p 8080:80` | 端口映射 |
| `mkdir -p a/b/c` | 建父目录 |
| `nmap -p 22,80` | 指定扫哪些端口 |

# 第 3 章 · 符号与标记

**这些是 shell 自己的语法。它们比命令更容易被忽略。**

## 3.1 重定向（输出去哪）

| 符号 | 作用 | 例子 |
|---|---|---|
| `>` | 覆盖写入文件 | `echo a > a.txt` |
| `>>` | 追加到文件末尾 | `echo b >> a.txt` |
| `2>` | 只重定向**错误**输出 | `命令 2> err.log` |
| `2>/dev/null` | 把错误**丢掉** | `find / -name x 2>/dev/null` |
| `&>` | 正确 + 错误都写 | `命令 &> all.log` |
| `2>&1` | 错误并到正常输出 | `命令 > a.log 2>&1` |
| `<` | 从文件读入 | `wc -l < a.txt` |
| `<<` | 多行输入（heredoc） | `cat > f << 'EOF'` |


## 3.2 管道与连接

| 符号 | 作用 | 例子 |
|---|---|---|
| `\|` | 前者的输出 → 后者的输入 | `ps aux \| grep ssh` |
| `\|\|` | 前者失败才跑后者 | `命令 \|\| echo 失败` |
| `&&` | 前者成功才跑后者 | `apt update && apt install` |
| `;` | 依次执行，不管成败 | `cd /tmp; ls` |
| `&` | 放后台跑 | `sleep 100 &` |

## 3.3 变量相关

| 符号 | 作用 | 例子 |
|---|---|---|
| `$变量` | 取变量的值 | `echo $PATH` |
| `${变量}` | 同上，能区分边界 | `echo ${NAME}好` |
| `${变量%.log}` | 删掉后缀 | `stem=${name%.log}` |
| `${变量##*/}` | 取文件名 | `f=${p##*/}` |
| `$?` | **上一条命令的退出码**（0 = 成功） | `echo $?` |
| `$1` `$2` | 脚本或函数的第 1、2 个参数 | `echo $1` |
| `$#` | 参数个数 | `echo $#` |
| `$@` | 所有参数 | `for a in "$@"; do ...` |
| `$(命令)` | **命令替换**：把输出当值 | `TODAY=$(date +%Y%m%d)` |
| `$((算式))` | 算术运算 | `echo $((3+5))` |

## 3.4 引号

| 写法 | 变量会展开吗 | 说明 |
|---|---|---|
| `"双引号"` | ✅ 会 | 最常用 |
| `'单引号'` | ❌ 原样 | 写 heredoc 时防 `$` 被替换 |
| `` `反引号` `` | ✅ 会 | 老式命令替换，**用 `$( )` 代替** |
| 不加引号 | ✅ 会，但会分词 | ❌ 危险 |

## 3.5 括号

| 写法 | 作用 | 例子 |
|---|---|---|
| `[ ]` | 条件判断（本质是个命令） | `[ -f a.txt ]` |
| `[[ ]]` | bash 增强判断（支持 `&&`、正则） | `[[ $a == *.log ]]` |
| `(( ))` | 算术 | `((i++))` |
| `{ }` | 命令分组 | `{ echo a; echo b; }` |
| `( )` | 子 shell | `( cd /tmp && ls )` |

**`[` 后面和 `]` 前面**必须有空格**，因为它是个真命令。**

## 3.6 通配与路径

| 符号 | 作用 | 例子 |
|---|---|---|
| `*` | 任意多个字符 | `ls *.log` |
| `?` | 任意一个字符 | `ls a?.txt` |
| `[abc]` | 其中一个字符 | `ls [ab].txt` |
| `~` | 家目录 | `cd ~` |
| `~/.ssh` | 家目录下的 .ssh | `ls ~/.ssh` |
| `/` | 根目录 / 路径分隔 | `cd /var/log` |
| `./` | 当前目录 | `./脚本.sh` |
| `../` | 上一级目录 | `cd ..` |

## 3.7 特殊标记

| 标记 | 作用 |
|---|---|
| `#` | 注释（`#` 后面的不执行） |
| `#!` | shebang，指定用哪个解释器 |
| `\` | 续行（后面**不能有空格**） |
| `!` | 取反（`[ ! -f a ]`）/ 历史命令（`!!`） |
| `/dev/null` | "黑洞"，写进去的东西消失 |
| `EOF` | heredoc 的结束标记（**可以换成任何词**） |

## 3.8 heredoc 长什么样

```bash
cat > 文件名 << 'EOF'
第一行
第二行
EOF
```

| 部分 | 作用 |
|---|---|
| `cat` | 本来打内容到屏幕 |
| `> 文件名` | 输出改道进文件 |
| `<< 'EOF'` | 输入改为"读到单独一行 EOF 为止" |
| `'EOF'` 加引号 | 防止内容里的 `$变量` 被提前替换 |
| 最后的 `EOF` | 结束标记，**必须顶格单独一行** |

**把 `EOF` 换成 `END`、`XXX` 都一样，只要前后一致。**

# 第 5 章 · 文本处理

## grep

```bash
grep "关键词" 文件
grep -i "关键词" 文件
grep -v "关键词" 文件
grep -c "关键词" 文件
grep -n "关键词" 文件
grep -r "关键词" 目录
```

**`-v` 是排除，不是显示。这条最容易记反。**

## awk

```bash
awk '{print $1}' 文件
awk '{print $1, $3}' 文件
awk -F: '{print $1}' /etc/passwd
```

# 第 11 章 · 报错 → 原因 → 解法

## Shell

| 报错 | 原因 | 解法 |
|---|---|---|
| `command not found` | 没装 / 打错 | `which 命令` |
| `Permission denied` | 没执行权限 | `chmod +x` |
| `bad interpreter: /bin/bash^M` | Windows 换行 | `sed -i 's/\r$//'` |
| `No such file or directory` | 路径错 | `pwd` + `ls` |
| `syntax error: unexpected end of file` | 少 `fi`/`done` | `bash -n` |
| `[: too many arguments` | 变量没加引号 | 加 `"$var"` |
| `find: unknown predicate` | find 没这参数 | `find --help` |
| `left operand of ... is not a valid integer` | `df` 取到了表头 | `awk 'NR>1'` |

## Python

| 报错 | 原因 | 解法 |
|---|---|---|
| `IndentationError` | 缩进不一致 | 统一 4 空格 |
| `SyntaxError: invalid syntax` | 少冒号/括号 | 看 `^` 的前一行 |
| `NameError` | 变量没定义 | 查拼写 |
| `TypeError: can only concatenate str` | 字符串加数字 | `f"{x}"` |
| `KeyError` | 键不存在 | `.get(k, 默认)` |
| `AttributeError: 'NoneType'` | 函数没 return | 加 `return` |
| `IndexError: list index out of range` | 下标越界 / 空列表 | 先判 `if not parts` |

## Docker

| 报错 | 原因 | 解法 |
|---|---|---|
| `Cannot connect to the Docker daemon` | 服务没起 | `systemctl start docker` |
| `"/x.html": not found` | COPY 的文件不在构建目录 | `ls` 看文件名 |
| `port is already allocated` | 端口被占 | 换端口 / `docker ps` 查 |
| `permission denied ... docker.sock` | 没用 sudo 或没加组 | `sudo` / `usermod -aG docker` |
| `TLS/SSL error: Certificate is NOT trusted` | 自签证书 + 客户端校验 | `--skip-ssl` |

## 终端操作

| 现象 | 原因 | 解法 |
|---|---|---|
| 一直 `>` 提示符 | 命令没写完（引号/`\`） | `Ctrl+C` |
| 敲什么都没反应 | 按了 `Ctrl+S` | `Ctrl+Q` |
| 报错行号格式怪（无 `line`） | 跑在 `sh` 下而非 bash | 查 shebang |
